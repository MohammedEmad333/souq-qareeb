# سوق قريب — Souq Qareeb

منصة مجتمعية **تجريبية** لعرض وبيع وتبديل والتبرّع بالأغراض المستعملة في غزة. يتيح الموقع للزائر تصفح المعروضات، وللعميل تقديم إعلان، ولإدارة المتجر مراجعته قبل نشره.

- الموقع المنشور: https://souq.edubridge.win
- مستودع المصدر: https://github.com/MohammedEmad333/souq-qareeb
- حزمة التسليم ومحددات التحقق: [دليل التسليم](docs/FINAL_HANDOFF_AR.md)
- سيناريو العرض أمام المشرف: [سيناريو المناقشة](docs/DEMO_SCRIPT_AR.md)
- قبول الإنتاج والدفع الاختباري (9 نوفمبر 2026): [السجل الموحّد](docs/PRODUCTION_ACCEPTANCE_2026_11_09_AR.md)
- نتائج الاختبارات وقيودها: [سجل الجودة](docs/QA_EVIDENCE_AR.md)

## الوظائف المنفذة

| الدور | الوظائف |
| --- | --- |
| زائر | استعراض المتجر، البحث، التصفية، تفاصيل المنتجات، تصفح الإعلانات المنشورة |
| Customer | حساب WooCommerce موحد، متابعة «إعلاناتي»، تقديم إعلان بيع/تبديل/تبرع بالصور، تعديل بيانات إعلان يملكه وإعادته للمراجعة، سحب إعلان |
| مدير/مسؤول المتجر | معاينة الإعلانات المعلّقة ومراجعتها وقبولها أو رفضها، إدارة منتجات WooCommerce |
| الدفع الأكاديمي | Stripe **Test Mode** لجميع الحسابات المسجّلة (Customer/مدير)، مع حظر الدفع للزائر غير المسجّل والمدفوعات الحقيقية في إعداد المشروع الحالي |

البيع من خلال السلة متاح للأغراض المؤهلة للشراء؛ أما إعلان التبديل أو التبرع فيستعمل التواصل مع صاحب الإعلان، وليس إتمام طلب من السلة. لا تُعرض ميزات غير منفذة مثل المراسلة الداخلية أو نظام مفضلة مستقل.

## التقنيات والهيكل

- WordPress + WooCommerce + PHP، وقاعدة MariaDB.
- قالب WordPress مخصص RTL داخل `wordpress/themes/souq-qareeb/`.
- إضافات MU مخصصة داخل `wordpress/mu-plugins/`.
- Docker Compose لنشر WordPress وقاعدة البيانات، مع عكس حركة HTTPS بواسطة البنية المنشورة.
- GitHub Actions لفحص صياغة PHP وDocker وأدوات النشر؛ لا تمثل فحوصات CI وحدها اختبار قبول وظيفي شامل.

```text
compose.yaml                      تشغيل WordPress وMariaDB
wordpress/themes/souq-qareeb/    القالب والواجهة العربية ووظائف الإعلانات
wordpress/mu-plugins/            إضافات التخصيص وحماية الدفع التجريبي
scripts/                         فحوصات وأوامر نشر موثقة
docs/                            حزمة المناقشة والتسليم وسجل الاختبارات
```

## تشغيل نسخة تطوير مستقلة

يمكن استخدام LocalWP أو Docker؛ **LocalWP ليس شرطًا لتشغيل المشروع أو عرضه**. يلزم تثبيت WordPress وWooCommerce، ونسخ القالب وإضافات MU إلى `wp-content`، ثم إنشاء/ربط صفحات Home وShop وCart وCheckout وMy Account و`add-listing`. أنشئ قاعدة بيانات ومستخدمين تجريبيين مستقلين؛ **لا تنسخ قاعدة بيانات الإنتاج أو بيانات زبائنه إلى جهاز عرض**.

للتشغيل باستخدام Compose، تتطلب `compose.yaml` متغيرَي البيئة `DB_PASSWORD` و`DB_ROOT_PASSWORD` في ملف `.env` محلي غير مرفوع، ثم `docker compose up -d`. المنفذ الداخلي الافتراضي لـWordPress هو `127.0.0.1:8095`. راجع [دليل القالب](wordpress/themes/souq-qareeb/README.md) و[دليل النشر الآمن للإضافات](scripts/README.md).

**أصول الهوية:** أُدرجت صور الشعار والواجهة الخمس الأصلية في المستودع عبر [PR #45](https://github.com/MohammedEmad333/souq-qareeb/pull/45) بعد التأكد من تطابقها مع نسخة الإنتاج. راجع [جرد الهوية البصرية](docs/BRAND_ASSETS_AR.md) وخطوات النشر.

## حماية البيانات والدفع

- لا تضع بيانات الدخول أو مفاتيح Stripe أو نسخ قاعدة البيانات أو الصور المرفوعة من المستخدمين في GitHub.
- `souq-demo-checkout.php` يجيز Stripe التجريبي لجميع الحسابات المسجّلة، ويمنع الزائر غير المسجّل وأي بوابة أخرى أو وضع دفع حقيقي. **لا تحذف هذا الحاجز أو تغيّر Test Mode إلى Live دون خطة إطلاق آمنة**.
- تحقق من إعدادات البريد الإلكتروني، ومعدل إساءة استخدام التسجيل، وصلاحيات المستخدمين قبل السماح بالتسجيل العام.
- النشر للإنتاج يجب أن يسبقه أخذ نسخة احتياطية ومراجعة تغييرات الملفات وفحوصات الخدمة.
