# جرد صور هوية سوق قريب

**الحالة بتاريخ 4 نوفمبر 2026 — مكتمل في مستودع المصدر.** تم دمج الأصول الأصلية الخمس في `main` عبر [PR #45](https://github.com/MohammedEmad333/souq-qareeb/pull/45) (commit `e8c387d6a50511879df6e36eee9b073d5f48d639`). أكد مالك خادم Oracle تطابق SHA-256 لكل صورة مع نسختها العاملة داخل حاوية WordPress المنشورة قبل رفعها. كما نجح فحص HTTP 200 بنوع محتوى صورة للملفات الخمسة على الإنتاج.

## الملفات التي أُضيفت

المجلد: `wordpress/themes/souq-qareeb/assets/images/`

| الملف | الاستخدام | الحجم وقت الرفع |
| --- | --- | ---: |
| `logo-header.png` | شعار الترويسة والتذييل | 105,739 بايت |
| `hero-mobile-image.webp` | الصورة الرئيسية | 64,560 بايت |
| `sell.webp` | بطاقة البيع | 26,352 بايت |
| `exchange.webp` | بطاقة التبديل | 22,892 بايت |
| `donate.webp` | بطاقة التبرع | 27,346 بايت |

هذه **صور القالب الثابتة فقط**، وليست صور المنتجات التي يرفعها العملاء. صور المنتجات ومحتويات قاعدة البيانات خارج المستودع.

## إعادة النشر

الصور أصبحت في GitHub، لكن Compose يستخدم `named volume` خاصًا بملفات WordPress؛ **التحديث بـ `git pull` وحده لا ينشر الملفات في الموقع**. عند إنشاء موقع WordPress جديد أو نشر قالب على سيرفر آخر:

1. انقل مجلد القالب كاملاً، بما فيه `assets/images/`، إلى `wp-content/themes/souq-qareeb/` داخل حجم WordPress المستخدم فعليًا.
2. تأكد من صحة صلاحيات الملفات ومن أن WordPress يستخدم القالب المخصص.
3. اختبر استجابة الملفات الخمسة برمز HTTP 200 ونوع محتوى `image/png` أو `image/webp`.
4. افتح الصفحة الرئيسية والصفحات الأخرى على هاتف وسطح مكتب للتأكد من عرض الشعار والصور دون تشوه.
5. احتفظ بنسخة احتياطية من الملفات وقاعدة البيانات قبل أي نشر للإنتاج.

## حدود الإثبات

- تم التحقق من **تطابق محتوى الملفات** المنشورة والملفات المضافة إلى GitHub باستخدام SHA-256 على Oracle.
- تم التحقق من **وصول ملفات الصور** بواسطة HTTP، لكن هذا لا يغني عن الفحص البصري للصفحات أو اختبار صلاحية استرجاع قاعدة البيانات.
- لا تزال سلامة البريد واختبار استعادة نسخة احتياطية على staging من مهام الإغلاق قبل التسليم النهائي.
