# جرد صور هوية سوق قريب

**الحالة بتاريخ 4 نوفمبر 2026:** واجهة الإنتاج تعرض الهوية المعتمدة، وقد أمكن استعادة ملفاتها إلى بيئة LocalWP عند صاحب المشروع. **الصور الثنائية الأصلية غير موجودة بعد في مستودع GitHub** في المسارات أدناه؛ لا يجوز وصف إعادة نشر القالب بأنها مكتملة الصور قبل نقلها.

## الملفات التي يتوقعها القالب

المجلد: `wordpress/themes/souq-qareeb/assets/images/`

| الملف | مكان استخدامه |
| --- | --- |
| `logo-header.png` | شعار الترويسة والتذييل |
| `hero-mobile-image.webp` | صورة القسم الرئيسي في الصفحة الرئيسية وصفحة الإعلان |
| `sell.webp` | بطاقة البيع |
| `exchange.webp` | بطاقة التبديل |
| `donate.webp` | بطاقة التبرع |

عند غيابها يعرض القالب عنوان الموقع نصًا أو مساحة خالية بدل الصورة، دون تعطل WordPress.

## نقل الأصول الأصلية بأمان من النسخة المحلية

من جهاز Omarchy الذي يحتوي على الصور المستعادة بالفعل:

```bash
cd ~/souq-qareeb-source
bash scripts/collect-brand-assets.sh \
  "$HOME/Local Sites/souq-qareeb-review/app/public/wp-content/themes/souq-qareeb/assets/images"
```

تحقق من محتوى الملفات وتراخيص استخدامها ومطابقتها للهوية المرئية، ثم **راجع تغييرات Git قبل إضافتها**:

```bash
git status --short
git diff --stat
# بعد المراجعة فقط:
git add wordpress/themes/souq-qareeb/assets/images/
```

افتح PR مستقلًا لإدراج الصور بعد الموافقة عليها. لا ترفع ملفات مستخدمين أو صورًا خاصة من `wp-content/uploads`، ولا تنشئ بدائل تصميمية غير معتمدة بحجة سد الفراغ.

## فحص نشر جديد

- تأكد من وجود الملفات الخمسة فعليًا تحت `wp-content/themes/souq-qareeb/assets/images/`.
- افتح الرئيسية على سطح المكتب والهاتف وراجع نسب الصور وغياب الروابط المكسورة.
- تأكد أن الشعار ليس اسم الموقع الافتراضي، وأن الصور تتطابق مع النسخة المعتمدة.
- احتفظ بنسخة احتياطية منفصلة للأصول مع الاستضافة ومصدر مشروع Git.

**ملاحظة:** يمكن أن تكون صور بعض البطاقات غير متاحة على الإنتاج نفسه؛ لا تُعلن اكتمالها إلا بعد التحقق لكل ملف.
